# פמי הנדסה - ניהול ומעקב

מערכת לניהול ומעקב מלא של פעילות החברה: מעקב משימות, מעקב סטטוס פרויקטים, חשבונות ופרוטוקולים.

## מבנה המאגר

| תיקייה | תוכן |
|---|---|
| `tasks/` | משימות ומעקב ביצוע |
| `projects/` | פרויקטים וסטטוס עדכני לכל פרויקט |
| `accounts/` | חשבונות, חשבוניות ומעקב תשלומים |
| `protocols/` | פרוטוקולים של ישיבות ופגישות |
| `docs/` | מסמכים כלליים ונהלים |

## הערות

- **שימו לב:** המאגר מוגדר כרגע כ**ציבורי** ב-GitHub. אין להעלות אליו חשבונות, פרוטוקולים או מסמכים אמיתיים עד שיוגדר כפרטי.

## מערכת הניהול (האתר)

`index.html` הוא אתר יחיד בעברית שעובד במחשב ובטלפון: לוח בקרה, משימות (לוח או רשימה), פרויקטים, חשבונות ופרוטוקולים.

- **הנתונים נשמרים בדפדפן של כל מכשיר בנפרד** ואינם עולים לגיטהב. לגיבוי או להעברה בין מכשירים: הגדרות וגיבוי, הורדת קובץ גיבוי, ואז טעינה במכשיר השני.
- **פרסום:** ב-GitHub, Settings, Pages, בוחרים Deploy from a branch, ענף `main`, תיקייה `/ (root)`. הכתובת תהיה https://femiengineering.github.io/femy-management/
- **התקנה בטלפון:** באייפון פותחים בספארי, שיתוף, "הוספה למסך הבית". באנדרואיד פותחים בכרום, תפריט, "התקנת אפליקציה".
- להרצה מקומית: `python3 -m http.server` בתיקיית המאגר, ואז http://localhost:8000
