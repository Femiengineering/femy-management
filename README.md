# פמי הנדסה - ניהול ומעקב

מערכת לניהול ומעקב מלא של פעילות החברה: מעקב משימות, מעקב סטטוס פרויקטים, חשבונות ופרוטוקולים.

## מבנה המאגר

| תיקייה | תוכן |
|---|---|
| `tasks/` | משימות ומעקב ביצוע |
| `projects/` | פרויקטים וסטטוס עדכני לכל פרויקט |
| `accounts/` | חשבונות, חשבוניות ומעקב תשלומים |
| `protocols/` | פרוטוקולים של ישיבות ופגישות |
| `docs/` | מסמכים כלליים ונהלים |

## הערות

- המאגר פרטי. אין לשתף אותו מחוץ לחברה.
- טכנולוגיה למערכת עצמה טרם נבחרה. בשלב זה המאגר משמש לתיעוד ולאחסון קבצים.
